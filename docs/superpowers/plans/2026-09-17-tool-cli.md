# `tool` CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap `joshuarli/tool` as a Python 3.14 `uv` application whose installed `tool` command exposes the destructive macOS SD-card qualification utility as `tool sdqual`.

**Architecture:** Use a packaged `src/tool` layout with stdlib `argparse` at the top-level CLI boundary and all SD-card-specific logic isolated in `tool.sdqual`. Safety-critical logic is factored into pure typed functions/dataclasses so it can be unit-tested without macOS hardware; subprocess orchestration remains explicit argv-only code with no shell.

**Tech Stack:** Python 3.14, stdlib only at runtime and in tests, `uv`/`uv_build` for project/build management, external `fio` and macOS `diskutil`/`caffeinate` for `sdqual`.

**Spec:** `docs/superpowers/specs/2026-09-17-tool-cli-design.md`

## Global Constraints

- Python requirement is exactly `>=3.14`; `.python-version` is `3.14`.
- Runtime Python dependency list is empty.
- Build backend is `uv_build`, using the current documented bounded backend requirement.
- Installed top-level command is `tool` via `[project.scripts] tool = "tool.cli:main"`.
- `tool sdqual` is macOS-only and destructive in normal mode.
- Never use `shell=True`; every subprocess is invoked with an argv sequence.
- Safety checks fail closed; no `--force` bypass exists for internal/system media.
- Human-readable fio output only; do not invent performance scores.
- Tests use stdlib `unittest` only.

```python
from __future__ import annotations

import argparse
from collections.abc import Sequence

from . import sdqual


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="tool")
    subparsers = parser.add_subparsers(dest="command", required=True)
    sdqual_parser = subparsers.add_parser("sdqual")
    sdqual.configure_parser(sdqual_parser)
    sdqual_parser.set_defaults(handler=sdqual.run)
    return parser


def main(argv: Sequence[str] | None = None) -> int:
    args = build_parser().parse_args(argv)
    return int(args.handler(args))
```
